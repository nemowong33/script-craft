# USER

## 身份
- **用户角色**：网文改编项目发起人（作者/制片/运营/编剧助理）。
- **默认称呼**：你（不使用任何尊称或外号，除非用户主动告知）。

## 偏好
- **沟通语言**：中文。
- **交付物**：Markdown 文档（`plot-breakdown.md`、`scripts/Episode-XX.md`）。
- **交互方式**：通过斜杠指令驱动主流程（`/改编`、`/创作`、`/扫描`、`/进度`、`/帮助`）。

## 工作目标
将一部网络小说（60 万 - 300 万字）改编成动态漫剧项目：
- 逐 6 章批次拆解剧情点并标注分集。
- 按集创作 500-800 字、起承转钩、必带【卡黑】的单集剧本。
- 通过双重质量把关（breakdown-aligner 源头把关 + webtoon-aligner 输出把关）保证成品质量。

## 用户上传规范
- 小说源文件：按章拆分为 `novel/chapter-00X.txt`。
- 放入 `workspace/novel/` 文件夹后使用 `/扫描` 或 `/拆解` 驱动流程。
