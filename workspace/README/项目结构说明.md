# 项目结构说明（OpenClaw 版）

## 1. 顶层结构

```
project/                                      # 项目根目录（即 OpenClaw workspace）
├── novel/                                    # 小说源文件目录（用户上传）
│   ├── chapter-001.txt
│   ├── chapter-002.txt
│   └── ...
├── plot-breakdown.md                         # 剧情拆解 + 分集标注 + 使用状态（改编后生成）
├── scripts/                                  # 单集剧本目录（改编后生成）
│   ├── Episode-01.md
│   ├── Episode-02.md
│   └── ...
└── .openclaw/                                # OpenClaw workspace 配置目录
    ├── IDENTITY.md                           # Agent 身份定义
    ├── SOUL.md                               # 人格、语气、边界
    ├── USER.md                               # 用户画像
    ├── TOOLS.md                              # 工具使用约定
    ├── AGENTS.md                             # 主 Agent 操作手册
    ├── skills/
    │   └── webtoon-skill/                    # 网文改编漫剧技能包
    │       ├── SKILL.md                      # 技能包核心配置
    │       ├── adapt-method.md               # 改编方法论
    │       ├── output-style.md               # 写作风格
    │       ├── templates/
    │       │   ├── plot-breakdown-template.md
    │       │   └── script-template.md
    │       └── examples/
    │           ├── plot-breakdown-example.md
    │           └── script-example.md
    ├── agents/                               # Sub-Agent（质量校验员）
    │   ├── breakdown-aligner/
    │   │   ├── IDENTITY.md                   # 身份
    │   │   ├── SOUL.md                       # 人格
    │   │   └── AGENTS.md                     # 操作手册 + 检查矩阵
    │   └── webtoon-aligner/
    │       ├── IDENTITY.md
    │       ├── SOUL.md
    │       └── AGENTS.md
    └── 说明/                                  # 本文档目录
        ├── 项目结构说明.md
        ├── 架构设计.md
        └── Agent流程.md
```

## 2. 分层职责

### 2.1 workspace 根层（业务数据）
| 路径 | 作用 |
|------|------|
| `novel/` | 用户上传的小说源文件（txt），一章一文件。 |
| `plot-breakdown.md` | 单一真相源：小说元信息 + 剧情拆解点 + 分集标注 + 使用状态。 |
| `scripts/Episode-XX.md` | 成品单集剧本，每集 500-800 字、起承转钩、带【卡黑】。 |

### 2.2 `.openclaw/` 配置层（Agent 运行时）

#### Workspace 根文件
OpenClaw 会在 session 起手时直接注入这些文件到上下文：

| 文件 | 作用 |
|------|------|
| `IDENTITY.md` | Agent 的名称 / 角色定位 / 签名 ASCII 艺术。 |
| `SOUL.md` | 人格、语气、边界、价值排序、硬约束。 |
| `USER.md` | 用户画像、偏好、工作目标。 |
| `TOOLS.md` | 本 workspace 的工具使用约定（Read / Write / Skill 调用 / Sub-Agent 调用规则）。 |
| `AGENTS.md` | **主 Agent 操作手册**：任务、总体规则、阶段流程、触发规则、指令集、初始化仪式。 |

#### `skills/webtoon-skill/`
唯一的"改编执行引擎"。按 OpenClaw `SKILL.md + YAML frontmatter` 规范组织。

| 文件 | 作用 |
|------|------|
| `SKILL.md` | 技能包入口（带 frontmatter）。声明阶段识别、资源整合、执行流程、改编原则。 |
| `adapt-method.md` | 网文改编方法论（通用版），包含冲突识别、情绪钩子、分集、压缩策略、类型化适配等。 |
| `output-style.md` | 写作风格规范：视觉化、快节奏、对话 ≤20 字、每集必【卡黑】等。 |
| `templates/plot-breakdown-template.md` | 剧情拆解格式模板。 |
| `templates/出稿-template.md` | 单集剧本格式模板。 |
| `examples/plot-breakdown-example.md` | 拆解参考示例。 |
| `examples/出稿-example.md` | 剧本参考示例。 |

#### `agents/*/`
每个 Sub-Agent 独立一个子目录，按 OpenClaw 规范拥有自己的 `IDENTITY.md / SOUL.md / AGENTS.md`。

| Sub-Agent | 职责 | 维度 |
|-----------|------|------|
| `breakdown-aligner/` | 剧情拆解源头把关 | 8 维 |
| `webtoon-aligner/`   | 单集剧本输出把关 | 11 维 |

两者都包含 YAML frontmatter（name / description / model / color），兼容 AgentSkills 风格的 Sub-Agent 发现机制。

## 3. 数据流路径

```
novel/chapter-XXX.txt
        │
        ▼
[主 Agent] —调用—► [webtoon-skill] —产出—► 剧情拆解（候选）
        │                                         │
        ▼                                         ▼
[breakdown-aligner] ◄───读基准─── adapt-method.md + 小说原文
        │
        │ PASS
        ▼
plot-breakdown.md  ◄───追加───  剧情点 + 分集标注（状态：未用）
        │
        ▼
[主 Agent] —调用—► [webtoon-skill] —产出—► 单集剧本批次（候选）
        │                                         │
        ▼                                         ▼
[webtoon-aligner] ◄───读基准─── plot-breakdown.md + adapt-method.md
        │
        │ PASS
        ▼
scripts/Episode-XX.md ◄── 批量写入
        │
        ▼
plot-breakdown.md ← 将本批剧情状态改为"已用"
```
