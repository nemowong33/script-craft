# 漫剧剧本原创 Skill

## 定位

本技能专注于**原创漫剧剧本**，不依赖小说原文，不读取 `adaptation/novel/`，不使用 `adaptation/plot-breakdown.md` 的剧情点状态。它从创意、题材、角色、主线冲突出发，生成适合动态漫剧/漫剧视频表达的原创项目。

## 与网文改编流程的边界

- 网文改编漫剧：使用 `adaptation-skill`，输入是小说章节，输出 `adaptation/plot-breakdown.md` 和 `adaptation/scripts/episode-XX.md`。
- 漫剧原创：使用本 skill，输入是创意需求，输出 `original/` 下的原创项目文件。
- 本 skill 不执行"章节扫描"、"剧情点未用/已用"、"原文还原"检查。

## 核心工作流程

```
/创作 → /方案 → /角色 → /大纲 → /出稿 N → /自检
```

## 文件生成规则

所有原创漫剧文件固定保存在 `original/`：

| 阶段 | 文件 |
|------|------|
| 创作方案 | `original/plan.md` |
| 角色档案 | `original/characters.md` |
| 分集大纲 | `original/outline.md` |
| 单集剧本 | `original/scripts/episode-XX.md` |
| 质量自检 | `original/quality-check.md` |

## 阶段要求

### 1. 创作启动

确认以下信息：

- 题材类型：玄幻、都市、重生、恋爱、悬疑、末世、奇幻、喜剧等。
- 目标受众：男频、女频、泛用户、青少年、成人向等。
- 项目规格：集数、单集时长、是否短篇试播。
- 情绪基调：爽燃、甜虐、搞笑、暗黑、热血、悬疑。
- 核心卖点：身份反差、金手指、复仇、误会、升级、打脸、真相揭露等。
- 禁区与偏好：不能出现的内容、必须保留的设定。

### 2. 原创方案

必须包含：

- 项目名：3 个备选。
- 一句话故事线。
- 世界观/时代背景。
- 主角目标、困境、成长方向。
- 核心冲突与长线反派。
- 三幕结构。
- 爽点/钩子矩阵。
- 关键转折集。
- 结局方向。

### 3. 角色开发

必须包含：

- 主要角色表：身份、目标、欲望、弱点、秘密、关系。
- 反派压迫力设计。
- 角色关系 Mermaid 图。
- 主角成长弧线。
- 关键配角功能，避免无功能角色。

### 4. 分集大纲

必须包含：

- 标准 20-60 集，可按用户指定调整。
- 每集：标题、核心事件、冲突、情绪钩子、结尾悬念。
- 每 2-3 集一个小爽点，每 5 集一个中爆点，关键转折集有大爆点。
- 上一集结尾必须自然牵引下一集开头。

### 5. 单集剧本

遵循动态漫剧表达：

- 每集 500-800 字。
- 1-3 个场景。
- 起承转钩四段式。
- 开场 3 秒进入冲突。
- 使用视觉描述符号：`※ 场景`、`△ 动作`、`【特效】`、`【卡黑】`。
- 对话短、直、冲突强，单句尽量不超过 20 字。
- 每集结尾必须有 `【卡黑】`。

## 前置读取规则

- `/角色` 前：读取 `original/plan.md`。
- `/大纲` 前：读取 `original/plan.md`、`original/characters.md`。
- `/出稿 N` 前：读取 `original/plan.md`、`original/characters.md`、`original/outline.md`、最近 2-3 集剧本。
- `/自检` 前：读取对应剧本与所有原创设定文件。

## 输出原则

- 永远不引用小说原文作为依据，除非用户明确把某部小说作为灵感来源。
- 原创设定一旦确认，后续章节必须保持一致。
- 如果用户提出新灵感，先判断影响范围，再更新方案/角色/大纲。
- 所有阶段完成后主动提示下一步指令。
