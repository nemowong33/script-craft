# 网文改编方法论 — adapt-method.md

> 本文件是 webtoon-skill 的**核心基准文档**，所有剧情拆解与剧本创作必须严格遵循。

## 一、改编总则（漫剧三法则）

1. **情绪钩子密度 > 故事完整性**：宁可砍主线支线，也要保证每集有强钩子。
2. **视觉冲击力 > 文学性描写**：用画面、动作、特效代替心理、环境、旁白。
3. **快节奏刺激 > 慢节奏沉浸**：3 秒入戏，每 30 秒必有推进，无废话无铺垫。

## 二、改编流程

```
小说原文 → ①类型确定 → ②冲突识别 → ③钩子提取 → ④分集标注 → ⑤单集剧本
```

## 三、冲突点识别与提取

### 冲突强度三级分类

| 等级 | 标识 | 定义 | 改编处理 |
|------|------|------|---------|
| 核心冲突 | ⭐⭐⭐ | 推动主线、改变主角命运或格局的关键事件 | 必拆必留，单独成集 |
| 次级冲突 | ⭐⭐ | 推进支线或铺垫的事件 | 合并成集或压缩 |
| 过渡冲突 | ⭐ | 日常、铺垫、环境描写，无明显张力 | 优先删除，或与⭐⭐合并 |

### 冲突类型标签
- **人物对立**：A vs B 直接对抗
- **力量对比**：弱对强 / 强对弱的实力碾压或反转
- **身份矛盾**：真实身份 vs 外表身份的反差
- **情感纠葛**：爱恨 / 误会 / 虐恋
- **生存危机**：死亡、绝境、倒计时
- **真相悬念**：线索、反转、隐藏设定

## 四、情绪钩子提取与标注

### 情绪钩子类型
- **打脸蓄力**：对方嘲讽/轻视 → 为后续打脸铺垫
- **碾压爽点**：主角实力碾压对方
- **金手指觉醒**：系统/异能/血脉觉醒瞬间
- **虐心痛点**：主角受辱、受伤、至亲离去
- **真相揭露**：重大设定/身份/阴谋被揭开
- **反转惊喜**：情势瞬间逆转
- **情感甜宠**：恋人互动高光
- **悬念埋线**：留白、铺垫、未解之谜

### 强度评分
| 分数 | 体感 | 改编处理 |
|------|------|---------|
| 10 | 观众"卧槽！"级震撼 | **必须单独成集**，600-800 字 |
| 8-9 | 观众爽/虐/急的核心高潮 | 核心爽点，1 个/集，500-700 字 |
| 6-7 | 观众有感觉的时刻 | 保留，1-2 个/集 |
| 4-5 及以下 | 情绪平淡 | **应删除** |

### 冲突密度达标线（每 6 章）
- 核心冲突（⭐⭐⭐）：中密度 2-4 个，高密度 ≥5 个
- 高强度钩子（10-8 分）：中密度 3-5 个，高密度 6-8 个

## 五、剧情拆解与分集标注

### 剧情点描述格式
```
【剧情n】[场景]，[角色A]对[角色B][做了什么]，[情绪钩子类型]，第X集，状态：未用
```

必填字段：场景、角色（谁对谁）、事件、情绪钩子类型、集数、状态。

### 分集策略
| 强度 | 每集剧情点 | 每集字数 |
|------|-----------|---------|
| 高（10-9 分） | 1 个 | 600-800 |
| 中（8-7 分） | 1-2 个 | 500-700 |
| 低（6 分） | 2-3 个 | 500-600 |

### 压缩策略

**必删内容**：
- 环境描写 / 心理独白
- 过渡情节 / 重复内容
- 与主线无关的支线剧情

**必留内容**：
- 冲突对话 / 动作场景
- 情绪爆点 / 关系展示
- 悬念设置 / 关键设定

**压缩方法**：
- 冲突合并（多场景合并成一场）
- 时间跳跃（跳过低密度段落）
- 信息前置（把后面的关键信息提前）
- 删繁就简（去除形容词和修辞）
- 支线取舍（砍次要角色视角）

## 六、单集结构（起承转钩四段式）

| 段 | 功能 | 约占 | 说明 |
|---|------|------|------|
| 起 | 场景切入 + 张力预告 | 15% | 3 秒进冲突，不要铺垫 |
| 承 | 冲突展开 | 40% | 对话/动作推进 |
| 转 | 意外/反转/爆点 | 30% | 核心爽点或虐点 |
| 钩 | 悬念【卡黑】 | 15% | **必须以【卡黑】结尾** |

## 七、关键集节奏

- **第 1 集**：3 秒入戏，结尾强钩子（为了让观众点第 2 集）
- **第 20 集**：**免费段结尾**，必须大爆点 + 强悬念（付费转化节点）
- **每 5 集**：1 个中爆点
- **每 2-3 集**：1 个小爽点

## 八、改编禁忌

**节奏禁忌**：开场慢、铺垫多、过渡长、节奏拖沓。
**内容禁忌**：心理描写过多、环境描写、过度文言文、网文万能句（"他想"、"他的脑海中"）。
**结构禁忌**：超过 3 个场景、单集 >800 字或 <500 字、**无【卡黑】**。
**改编禁忌**：过度忠于原著、保留小说铺垫、心理活动未转化为动作/对话。
**视觉禁忌**：无画面感、对话超过 20 字、无视觉符号。

## 九、类型化适配策略

| 类型 | 必强化 | 必删除 |
|------|-------|-------|
| 玄幻 / 武侠 | 境界突破、越级碾压、打脸场景 | 修炼原理长篇解释 |
| 都市 / 现代 | 身份反差、财富对比、真相大白 | 职场细节、商战铺垫 |
| 言情 / 古言 | 误会产生、虐心痛苦、甜宠片段 | 内心独白、风景 |
| 悬疑 / 推理 | 关键线索、反转时刻、真相揭露 | 过多次要嫌疑人 |
| 科幻 / 末世 | 危机爆发、异能觉醒、黑科技展示 | 世界观长篇设定 |
| 重生 / 复仇 | 前世今生对比、先知优势、打脸仇敌 | 前世冗长回忆 |
