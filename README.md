# Script Craft - 网文改编漫剧与短剧创作平台

> 🎬 专业的网络小说改编动态漫剧 + 爽文短剧剧本创作智能工作流

## 项目简介

Script Craft 是一个基于 AI 驱动的编剧工作区，由经验丰富的"钳多多"（CHANDOR）作为主 Agent，支持两套专业流程：

- **网文改漫剧**：类型确定 → 剧情拆解 → 分集标注 → 单集剧本。
- **短剧剧本创作**：题材选择 → 创作方案 → 角色开发 → 分集目录 → 分集剧本 → 质量自检。

## ✨ 核心特性

- **专业改编流程**：完整的网文到漫剧的专业转化
- **短剧创作流程**：完整承接爽文短剧行业写作规范，覆盖方案、角色、目录、分集和合规
- **多重质量门禁**：剧情拆解、漫剧剧本、短剧方案/剧本质量检查
- **智能拆解**：自动提取情绪钩子、压缩冲突密度、转化视觉语言
- **结构化输出**：每集 500-800 字，起承转钩四段式结构
- **分集标注**：清晰的剧情点管理，标记使用状态
- **短剧强节奏**：50-70 集目录规划、付费卡点、爽点矩阵、结尾悬念
- **合规审核**：按短剧合规清单检查内容风险并给出可播化修改建议

## 🚀 快速开始

### 1. 初始化项目

```bash
# 确保你好！我是钳多多，一位专注于网文改编的编剧。
```

### 2. 上传小说

将小说章节放入 `novel/` 文件夹，每章保存为单独的 txt 文件：
- `chapter-001.txt
- `chapter-002.txt
- ...

### 3. 开始改编

使用指令驱动漫剧工作流：

| 指令 | 功能 |
|------|------|
| `/拆解` | 执行剧情拆解阶段（拆解 6 章 + 分集标注 + 质量检查） |
| `/出稿` | 执行单集剧本创作阶段 |
| `/扫描` | 自动扫描 novel/ 文件夹寻找小说文件 |
| `/进度` | 显示当前项目进度 |
| `/帮助` | 显示所有可用指令和使用说明 |

### 4. 开始短剧创作

| 指令 | 功能 |
|------|------|
| `/短剧开始` | 启动题材、受众、基调、集数、语言确认 |
| `/短剧方案` | 生成 `drama/创作方案.md` |
| `/短剧角色` | 生成 `drama/角色档案.md` |
| `/短剧目录` | 生成 `drama/分集目录.md` |
| `/短剧分集 N` | 生成第 N 集剧本到 `drama/scripts/` |
| `/短剧自检` | 生成 `drama/质量自检.md` |
| `/短剧合规` | 执行短剧合规审核 |

## 📝 改编三法则

1. **情绪钩子密度 > 故事完整性
2. **视觉冲击力 > 文学性描写
3. **快节奏刺激 > 慢节奏沉浸

## 🎯 漫剧硬约束

- **每集时长**：1-2 分钟
- **字数控制**：500-800 字
- **场景数**：1-3 个场景
- **结构**：起承转钩四段式
- **结尾**：必须卡黑

## 🎯 短剧硬约束

- **标准规模**：50-70 集（可按需求调整）
- **单集长度**：每集不少于 800 字
- **场次结构**：3-5 个场次
- **爽点密度**：每集至少 2 个爽点或反转
- **付费卡点**：通常第 8-12 集设置免费转付费节点
- **格式规范**：中文短剧格式或英文出海格式自动切换
- **质量检查**：创作方案、角色、目录、分集剧本均需通过 short-drama-aligner
