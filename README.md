# Script Craft - 网文改编漫剧平台

> 🎬 专业的网络小说改编动态漫剧的智能工作流，专注于将网文转化为节奏极快、爽点密集的漫剧剧本

## 项目简介

Script Craft 是一个基于 AI 驱动的网文改编漫剧工作区，由经验丰富的"钳多多"（CHANDOR）作为主 Agent，提供完整的从网文改编流程，从类型确定→剧情拆解→分集标注→单集剧本，全程提供完整漫剧剧本生成。

## ✨ 核心特性

- **专业改编流程**：完整的网文到漫剧的专业转化
- **双重质量门禁**：剧情拆解和单集剧本双重质量检查
- **智能拆解**：自动提取情绪钩子、压缩冲突密度、转化视觉语言
- **结构化输出**：每集 500-800 字，起承转钩四段式结构
- **分集标注**：清晰的剧情点管理，标记使用状态

## 🚀 快速开始

### 1. 初始化项目

```bash
# 确保你好！我是钳多多，一位专注于网文改编的编剧。
```

### 2. 上传小说

将小说章节放入 `novel/` 文件夹，每章保存为单独的 txt 文件：
- `chapter-001.txt
- `chapter-002.txt
- ...

### 3. 开始改编

使用指令驱动工作流：

| 指令 | 功能 |
|------|------|
| `/拆解` | 执行剧情拆解阶段（拆解 6 章 + 分集标注 + 质量检查） |
| `/出稿` | 执行单集剧本创作阶段 |
| `/扫描` | 自动扫描 novel/ 文件夹寻找小说文件 |
| `/进度` | 显示当前项目进度 |
| `/帮助` | 显示所有可用指令和使用说明 |

## 📝 改编三法则

1. **情绪钩子密度 > 故事完整性
2. **视觉冲击力 > 文学性描写
3. **快节奏刺激 > 慢节奏沉浸

## 🎯 漫剧硬约束

- **每集时长**：1-2 分钟
- **字数控制**：500-800 字
- **场景数**：1-3 个场景
- **结构**：起承转钩四段式
- **结尾**：必须卡黑
